# DSH Remote 使用说明

一个人的自用远程控制：**手机（鸿蒙 NEXT）当遥控器，电脑上的 DSH 干活，活干完手机通知栏弹提醒。**

---

## 1. 它由两部分组成

| 部分 | 位置 | 作用 |
|---|---|---|
| **桥插件** `dshremote-bridge` | 电脑，装进 DSH 的 desktop profile | 把 DSH 的回合结束事件转成手机能拉取的消息；把 DSH 的网页转给手机（带鉴权） |
| **手机 App** `DSH Remote` | 手机 | 内嵌 DSH 网页 + 后台轮询 + 本地通知；鸿蒙（`.hap`）与安卓（`.apk`）两个版本功能一致 |

两者之间平时只走局域网；出门在外走 Cloudflare 隧道（见第 5 节）。

---

## 2. 电脑端（一次性）

插件已经装好并 link 到源码目录：

```
C:\Users\user\Desktop\dshremote\bridge   ← 改代码改这里，改完重启 Desktop 生效
C:\Users\user\.dsh\dshremote-bridge.token ← 配对 token
C:\Users\user\.dsh\dshremote-bridge.log   ← 桥的日志（排障先看它）
```

- 端口：桥 `3088`、DSH 网页反代 `7627`（DSH 本体端口每次启动都会变，桥会自动跟随，不用管）。
- 查状态：浏览器打开 `http://127.0.0.1:3088/health`。
- 看 token：

```powershell
Get-Content "$env:USERPROFILE\.dsh\dshremote-bridge.token"
```

---

## 3. 手机端配对（一次性）

1. 手机连上**和电脑同一个 Wi-Fi**。
2. 打开 `DSH Remote`（安卓版没有相机扫码，用「粘贴配对链接」或直接点电脑上复制出来的深链；鸿蒙版可以扫码），填：
   - 电脑 IP：形如 `192.168.1.23`（用 `ipconfig` 看电脑 WLAN 的 IPv4）
   - 端口：保持默认 `3088`（**别手输，输会变成 30883088**）
   - 配对 token：上面那条命令读出来的字符串
3. 点「测试连接」→ 出现 `桥 0.2.2 · 协议 v1` 就是通了。
4. 点「保存并进入」→ 进入 DSH 界面。

之后每次打开 App 会直接进主界面，不用再填。

---

## 4. 日常怎么用

- 手机就是 DSH 的网页界面：新建/切换会话、发消息、看流式回复，和电脑上一模一样。
- 电脑那边跑完一个回合，手机通知栏会弹「会话标题 · done + 回复开头」。
- 通知是 App 自己发的本地通知：**App 得活着**（后台常驻，已开长时任务 `dataTransfer`）。
- 点通知会回到 App。

---

## 5. 出门在外（固定地址：Tailscale Funnel，推荐）

不在同一 Wi-Fi 时用隧道，电脑不用开公网端口。

**为什么推荐 Tailscale Funnel**：它给的是**永久固定域名** `https://<设备名>.<tailnet>.ts.net`，电脑重启、换 Wi-Fi、换 4G 都不变——手机里只配一次，之后同 Wi-Fi 走局域网、在外走这个固定地址，都不用再扫码换地址。

### 5.1 第一次配置（一次性）

1. 装 Tailscale（管理员权限一次）：`winget install Tailscale.Tailscale`，或下载 `tailscale-setup.msi`。
2. 登录（会打开浏览器，用 Google / Microsoft / GitHub 邮箱都行，这个账号就是你的 tailnet）：
   ```powershell
   & 'C:\Program Files\Tailscale\tailscale.exe' up --hostname=dsremote --accept-dns=false
   ```
3. 在控制台开两个开关（**两个都要**，否则 Funnel 起不来）：
   - https://login.tailscale.com/admin/dns → **HTTPS Certificates** → **Enable HTTPS**
   - 命令行跑 `tailscale funnel`，它会打出一个 `https://login.tailscale.com/f/funnel?node=…` 的链接，打开点 **Enable Funnel**
4. 一键开 Funnel 并写进桥配置：
   ```powershell
   cd C:\Users\user\Desktop\dshremote
   .\tools\enable-funnel.ps1 -BridgeConfig "$env:USERPROFILE\.dsh\profiles\desktop\cordis.patch.yml"
   ```
   脚本会：`tailscale up` 登录 → `tailscale funnel --bg --https=443 http://127.0.0.1:3088` → 回打 `https://<域名>/health` 自证 → 把 `publicUrl` 和 `tunnel: off` 写进桥配置。
5. 重启一次 Desktop，桥就进入「固定地址模式」（不再拉 cloudflared）。

### 5.2 之后每次开机

- `tailscaled` 是随系统启动的服务，Funnel 配置存在它的状态里，**开机自动恢复**，不用你手动跑任何东西。
- 桥启动时回打一次 `https://<域名>/health` 自证；之后每 60 秒复核一次，挂了会在日志里写 `隧道 … 已失效`。

### 5.3 手机端

- 扫二维码（电脑端左下角图标 → 「手机遥控 DSH」）：二维码里同时带**局域网地址**和**固定公网地址**。
- 进 App 后它会先探局域网（2 秒超时），通就走局域网，不通自动切到固定地址。切换是你无感的，界面不显示网络状态。

### 5.4 备选：Cloudflare 快速隧道

`.\tools\tunnel.ps1` 仍然可用，但域名**每次重启都会变**、还会被 Cloudflare 回收（表现为 530 / Error 1033），只适合临时验证。

- 隧道是「快速隧道」没有 Access 保护。桥这一侧的安全是：所有敏感接口都要 token（二维码里只有 60 秒一次性码）、非回环来源一律要求 token、`/ai-fix` 只允许本机回环调用、按来源限流、非法 Host 直接 400。

## 6. 出问题先看这里

| 症状 | 原因 | 处理 |
|---|---|---|
| 「连不上：Invalid URL format」 | 端口框被追加成 `30883088` | 重装 App 或只改 IP/token，端口留默认 |
| 测试连接失败 | 不在同一 Wi-Fi / 电脑睡了 / 桥没起来 | 先 `http://127.0.0.1:3088/health` 看桥，再 `ping` 手机 IP |
| 页面显示 `dsh web authentication required` | cookie 没写进去（Desktop 重启后 DSH 端口变了，旧 cookie 的 authority 失效） | App 里点「刷新」，或「设置」→ 重新「保存并进入」以重新领 cookie |
| 页面能开但发不出消息 / 一直转圈 | Desktop 重启过，trustedHosts 列表是旧的 | 重启 Desktop 后在 App 里「设置」→「保存并进入」 |
| 收不到通知 | 通知权限被关 / App 被系统清掉 | 设置里给 `DSH Remote` 开通知；从最近任务里别划掉它 |
| 隧道下页面打不开 | Funnel 没开 / Tailscale 没登录 / 电脑关机 | 电脑上跑 `tailscale funnel status` 看是否 `Funnel on`；断了重跑 `.\tools\enable-funnel.ps1` |
| 电脑上的面板体检里「隧道 → 桥」偶尔超时 | 本机 DNS 解析 `*.ts.net` 抖动（不是隧道坏了） | 桥会缓存上次解析到的入口 IP 并在 DNS 失败时自动复用；面板点「重新测试」即可，不用改配置 |
| 浏览器/面板偶尔出现 502 | DSH 电脑端正好在重启，反代上游连接被重置 | 桥对 GET/HEAD 自动重试 3 次；仍失败就刷新一次，等 Desktop 起来就好 |
| 隔一夜就连不上 | 电脑休眠、或手机换了 Wi-Fi、或 IP 变了 | 电脑电源设置改成不休眠；固定地址模式下换网络不用改任何配置 |

## 7. 已知限制（v0.2.2）

- 固定地址靠 Tailscale Funnel：电脑关机就断，开机自动恢复；手机不在同一 Wi-Fi 也不用手动做任何事。
- 电脑休眠 = 断（和有没有隧道无关）。
- 手机重启、或系统清后台之后，通知会停，重新打开 App 才恢复。
- 包名还是 `com.example.myapplication`（调试证书 `.p7b` 按包名绑定，改名要重回 DevEco 自动签名）。
- 鸿蒙的 ArkTS WebSocket 发不出帧（`user data is nullptr`），所以通知走 **3 秒一次的 HTTP 轮询**，不是推送；也因此没法做到"App 被杀还能收"。

## 8. 改代码之后怎么重新装

```powershell
# 电脑端（桥）：改完直接重启 Desktop
# 手机端（App）：
$env:DEVECO_SDK_HOME='E:\dev\DevEco Studio\sdk'
$env:HVIGOR_HOME='E:\dev\DevEco Studio\tools\hvigor'
cd C:\Users\user\Desktop\dshremote\app
& 'E:\dev\DevEco Studio\tools\hvigor\bin\hvigorw.bat' assembleHap --mode module -p product=default -p buildMode=debug --no-daemon

$hdc='E:\dev\DevEco Studio\sdk\default\openharmony\toolchains\hdc.exe'
& $hdc install -r 'C:\Users\user\Desktop\dshremote\app\entry\build\default\outputs\default\entry-default-signed.hap'
& $hdc shell "aa force-stop com.example.myapplication"
```

签名材料在 `C:\Users\user\.ohos\config\`，工程里的 `.sign\sign-config.json5` 会被 hvigor 自动读取，**不需要开 DevEco 也能命令行出签名包**。

## 9. 安卓版（可选）

安卓版是同一套功能的纯 Java 实现（不依赖 Gradle、不引第三方库），Release 里直接下 `dshremote-android-<ver>.apk` 装就行。

- 系统要求：Android 7.0（API 24）及以上。
- 首次打开：只有一屏「配对链接 + token」，扫码/粘贴配对链接后点「连接」。
- 已配对：直接进全屏 DSH，右上角一个齿轮回到设置页。
- 通知：前台服务每 3 秒拉一次 `/events`，回合结束弹「标题 · done + 回复开头」；需要通知权限，Android 13+ 首次会请求。
- 深链：`dshremote://pair?...` 可以直接拉起 App 并自动配对（用手机浏览器打开配对链接即可）。

自己构建：

```powershell
cd C:\Users\user\Desktop\dshremote\android
.\build.ps1        # 需要 Android SDK build-tools 34 与 JDK（脚本顶部可改路径）
# 产物：android\dshremote-android-0.2.0.apk（自签 debug 证书）
```

> 说明：本机没有安卓真机，APK 只做了静态验证（`aapt2 dump badging` + `apksigner verify` + dex 类清单），首次真机安装如遇问题请贴 logcat。
